## Layout

`src/layouts/BaseLayout.astro`: head (OG/Twitter, canonical from `Astro.site`, font preloads with
`?url` imports), an inline pre-paint script that latches the colour scheme (US-7, 11-14: `html[data-scheme]` before first paint and after every swap; see `communication.md`), `<ClientRouter />`, `global.css` + `pager-scale.css` (the pager's skin) + `site-scheme.css` (the corner pager's seat) + `scheme.css` (the black and blue schemes; the order is load-bearing, equal-specificity ties go to the later sheet) + four `*-tune.css` sheets (kept at layout level on
purpose), server-computed `body.route-*` classes, skip link, hidden Netlify contact form,
`<SiteShell client:load transition:persist>`, `<SiteTagline client:load transition:persist>` and `<SiteScheme client:idle transition:persist>` (the colour-scheme corner pager, SQ-92, before `#main`),
`<div id="main"><slot /></div>`, and an inline script that runs Lenis `syncRoute()` on
`astro:page-load`, installs `homeWarm.js` (SQ-33, 11-08: on every route but home it fetches `/` into
memory on an idle beat, and `astro:before-preparation` for `/` wraps the router's own `e.loader` so
its one fetch of `/` is served that copy; 3-min TTL, form posts and `/?query` fall through;
`?homewarm=0` off) and arms the `swm:returnToWork` sessionStorage flag on popstate. It also awaits the
Client Roster (`getDirectoryData()` → `toDrawerRoster`, `src/lib/clientCoverage.js`; `[]` and a
`[roster]` warning if the read fails) and hands it to `SiteShell` as `roster` (11-03).
