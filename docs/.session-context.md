## Decisions & Context

### Frontend Architecture
- **Astro + React Islands**: The `/work` route uses `client:load` React islands within Astro pages. All interactive components (ProjectDirectory, FilterBar, etc.) are React; the page shell is Astro SSR.
- **CSS Multi-Column Masonry**: Using `columns: 4` CSS layout instead of JS-based masonry for performance. Items use `break-inside: avoid` and `margin-bottom: var(--space-1)` for uniform spacing.
- **Fixed Chrome Pattern**: The work header + filter bar is `position: fixed` (`.work-chrome`). The media grid's top padding is dynamically set via `ResizeObserver` on the chrome element to prevent clipping.
- **Image Resolution**: Centralized via `imageConfig.js` — standard assets at 800px width, wide assets at 1200px. Both MediaCard and AlbumArtTicker pull from this config.

### Filter System
- **Scroll Detection**: Uses raw `scrollWidth > clientWidth` comparison with `overflow-x: auto` always enabled on the bar. No CSS class toggling — purely state-driven.
- **Bidirectional Arrows**: Right arrow shows when `scrollLeft + clientWidth < scrollWidth - threshold`. Left arrow shows when `scrollLeft > threshold`. Both use GSAP `translateX` slide-in/slide-out.
- **Arrow Styling**: Brand blue (`--color-electric-blue`) background, black arrow glyphs. The wrapper has no padding so arrows can reach viewport edges. The bar itself has `padding-left: var(--space-6)` for header alignment.
- **Motion Principles**: Exit animations are 60-70% of entrance duration. Bounce loops are created once and toggled via play/pause.

### Video Playback
- **Mux HLS**: Videos use `useHls.js` hook with HLS.js for adaptive streaming. Lazy loading via IntersectionObserver.
- **Load-Gated Transitions**: All assets start at `opacity: 0` and gain `--loaded` modifier via `onLoad` (images) or `onCanPlay` (videos).

### Ticker (Deprecated)
- **AlbumArtTicker**: The service-type ticker was fully deprecated and removed from the filter bar. The AlbumArtTicker component exists but is separate from the filter system.
