## Decisions & Context

- **Scale is THE pager** (Nathan, 09-05): tape + tuner deleted; the
  legacy rail kept ONLY as the parked rail-arm's front end.
- **Sizes step at the DETENT, ink and stagger flow per frame** (r11e/g):
  `--ndd` (integer, from `--scale-cur`) drives the size curve so text
  lands with the box; `--ndr` (continuous) drives ink and the stagger.
- **One name cap per tier** (r11d/09-07): roster cap = sel cap, so a
  long name clips identically everywhere — no jump at the detent. ≤768
  evaluated from the viewport; desktop 20rem.
- **Every looping animation seeks the wall clock when it arms** — GSAP
  via `totalTime(now mod period)`, CSS via `animation-delay =
  −(now mod duration)`. Never strip-then-re-add an animating attribute.
- **Unregistered custom props keep calc()/pow() unevaluated in
  getComputedStyle** — verify curves by screenshot; but computed
  `max-width` DOES resolve to px (why `capOf` reads the property).
- **Warp horizon**: clamp cos at the drum's horizon or wheel clones past
  δ = R·π/2 render mirrored.
- **Chip wipe**: a solid block on an expo-out ease reads as a cut on a
  phone — give exits their own beat/ease; WebKit interpolates px↔%
  clip-path fine (tested).
- **Guide doctrine**: add a param → add a row → `--check` PASS (270).
- **Deploy law**: production = merge to `main`; branch pushes rebuild
  the stable preview. Everything is pushed.
