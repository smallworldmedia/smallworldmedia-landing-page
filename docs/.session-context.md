## Decisions & Context

- **Service resolution is decoupled from filenames.** `mediaAsset.services` is a reference array to `serviceTag` documents — no filename conventions needed.
- **Two manifest modes:** Mode 1 (header `services:`) for curated collections, Mode 2 (per-row `serviceType`) for root directories needing granular control.
- **Fallback logic:** row `serviceType` → header `services` → `undefined`. This lets Mode 1 manifests stay simple while Mode 2 has full control.
- **Client naming:** Slugs generated via `toSlug()` helper. Manifest `client:` must match seeded `name` exactly (e.g., "HOMEGRWXN" not "HOMEGRWXN.").
- **HOMEGRWXN folder** is named `HOMEGRWXN.` on disk (with period) but the client document is `HOMEGRWXN` (no period).
- **Affiliations schema** uses `affiliations[]` array with `{client, relationship}` objects — relationships: `signed-to`, `managed-by`, `label-of`, `sublabel-of`, `partner`.
- **Image uploads skipped** in first ingestion (`--skip-upload` flag). Documents are created with all metadata but no CDN image references yet.
